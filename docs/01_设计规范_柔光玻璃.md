## 0. 一句话基线

> 界面是一层「柔光玻璃」：底下一片低饱和渐变光，玻璃浮在光上，内容压在玻璃里。任何一块玻璃都必须能看见背后的光，但绝不能让文字失去对比。

三条不可让渡的底线：

1. 封面/背景之上的一切文字，必须有 scrim（渐变遮罩）兜底，禁止"裸字压图"。
2. 同屏大面积模糊层 ≤ 3 块；列表滚动期间模糊降级。
3. 任一信息层级的正文对比度 ≥ 4.5:1，次要文字 ≥ 3.5:1 且不小于 12sp。

## 1. 调研提炼（开源生态 → 设计决策）

### 1.1 样本与提炼点

| 参考 | 类型 | 可提炼之处 | 本项目采纳 / 改造 |
|---|---|---|---|
| FongMi/TV（TVBox 分支） | 聚合客户端 | `sites` 数组驱动的源列表；源 = 配置项而非硬编码；首页 = 分类 tab + 站点 tab 两套入口 | 采纳"源即配置"。首页做「内容维度」分区，源管理收进二级设置，避免首屏被源列表占满 |
| CatVod / tbox 系 | 聚合客户端 | 播放器 `parses` 多解析器优先级链、`flags` 平台识别、`ads` 过滤域名列表 | 采纳「解析链」概念，抽象为"播放线路"。广告域名过滤放进网络层，不占用 UI |
| TVBox 多仓（仓库订阅） | 配置分发 | 一个 URL 返回多个仓库 → 用户挑仓 → 再拉具体配置的三级结构 | 采纳三级导入：订阅地址 → 仓库选择 → 站点勾选合并，保留"多仓"心智 |
| Just Player | 播放器 | 极简控制条、双击左右跳转、长按倍速、字幕/音轨面板下沉、无干扰全屏 | 采纳手势与"控件即隐形"哲学；控制条改为玻璃浮层 |
| NextPlayer | 播放器 | 本地媒体库 + 播放器一体；文件浏览层级清晰；播放进度持久化 | 采纳本地文件夹入口与"继续观看"数据模型 |
| mpv-android | 播放器内核壳 | 手势区划分（左亮度 / 右音量 / 中进度）、双击复位、硬解切换 | 采纳三段式手势分区与双击复位 |
| Jellyfin 客户端 | 媒体库 | 详情页信息优先级（标题→主操作→剧集→简介→演职员）；海报 2:3 强约束；播放位置续播 | 采纳详情页信息顺序与 2:3 封面比例；弱化"库"概念，改为"收藏/历史" |
| 主流长视频 App（信息流） | 内容分发 | 首屏大图 banner + 横滑推荐 + 双列海报网格；分区标题右侧"更多" | 采纳三段式首屏；卡片统一 2:3，横滑卡用 16:9 宽幅 |
| 短视频流（沉浸） | 交互 | 上下滑换内容、单击暂停、右侧操作簇、进度不可见 | 仅采纳"上下滑换集"用于剧集连续播放，不做全屏短视频流 |

### 1.2 设计方向（结论）

- **信息架构**：`首页（内容发现） → 详情（决策） → 播放（消费）`，源管理、搜索、历史作为支撑面。
- **首屏策略**：不做"站点列表式"首屏。首屏固定三段：`继续观看`（有数据才出现）→ `今日推荐` 大图 → `分类分区` 双列网格。
- **源与内容解耦**：同一部影片可挂多条线路（不同源），详情页以"线路"而非"源"呈现给用户。
- **视觉**：柔光玻璃（Soft Glass）。以"光"为底、以"玻璃"分层、以"胶囊"为交互语言。
- **动效**：短、轻、有因果。不做无来源的弹跳；玻璃浮现必须伴随模糊值同步上升。

## 2. 信息架构

### 2.1 页面地图

```
启动
├─ 首页 Home（默认）
│   ├─ 继续观看（横滑，条件展示）
│   ├─ 今日推荐（16:9 大图，1~3 张轮播）
│   ├─ 分区 A/B/C…（双列 2:3 网格，每区 6~12 项 + "更多"）
│   └─ 顶部：搜索胶囊 + 主题切换
├─ 搜索 Search
│   ├─ 历史/热搜
│   ├─ 联想结果（防抖 300ms）
│   └─ 结果列表（列表/网格切换）+ 筛选条
├─ 详情 Detail
│   ├─ 头图区（海报模糊铺底 + 信息玻璃卡）
│   ├─ 主操作：播放 / 续播 / 收藏
│   ├─ 线路切换（底部面板）
│   ├─ 选集（网格，支持倒序/分组）
│   ├─ 简介（3 行折叠）
│   └─ 相关推荐（横滑）
├─ 播放 Player
│   ├─ 全屏画面
│   ├─ 顶部玻璃条（返回/标题/更多）
│   ├─ 中央控制条（进度 + 播放键 + 手势反馈）
│   ├─ 底部：选集抽屉把手 + 倍速 + 线路
│   └─ 手势层：亮度/音量/进度/长按倍速
├─ 源管理 Sources
│   ├─ 已启用源列表（卡片 + 开关 + 状态点）
│   ├─ 导入：URL / 剪贴板 / 二维码 / 本地文件
│   ├─ 仓库（多仓）选择
│   └─ 站点勾选与合并
└─ 设置 Settings
    ├─ 播放（硬解/倍速记忆/跳过片头）
    ├─ 外观（主题/模糊强度/动效）
    └─ 网络（UA/代理/超时）
```

### 2.2 导航规则

- 无底部导航栏（影音应用内容优先，避免 48dp 永久占用）。
- 以"返回栈 + 手势返回"为主；首页到详情用共享封面转场（shared element，封面卡片 → 详情头图）。
- 播放页为全屏独立栈，退出播放回到详情页，并保留选集滚动位置。
- 源管理、设置从首页右上角入口进入（侧滑抽屉式），不打断内容流。

### 2.3 首页分区策略

| 分区 | 数据来源 | 数量 | 展示形式 | 出现条件 |
|---|---|---|---|---|
| 继续观看 | 本地播放记录 | 3~8 | 横滑宽卡（16:9 缩略 + 进度条） | 存在未看完记录 |
| 今日推荐 | 首页推荐接口 / 站点推荐聚合 | 1~3 | 16:9 大图轮播，玻璃信息条 | 推荐非空 |
| 分区 A（例：热门） | 分类接口 | 6~12 | 双列 2:3 海报卡 | 分类非空 |
| 分区 B（例：新上架） | 分类接口 | 6~12 | 双列 2:3 海报卡 | 同上 |
| 分区 C（例：完结精选） | 分类接口 | 6~12 | 双列 2:3 海报卡 | 同上 |

规则：
- 分区顺序由配置下发（`home_sections`），客户端不写死分类名。
- 全部分区为空 → 进入**首启空态**（引导导入源），不得展示空白骨架。
- 单分区失败不影响其他分区渲染；失败分区直接不占位（不显示"加载失败"占位块，避免首屏碎片化）。
- 分区标题 17sp/600，右侧"更多 ›" 13sp/次级色，整行 44dp 可点。

## 3. 布局与网格

### 3.1 栅格

- 屏幕左右安全边距：**16dp**（375dp 宽下内容宽 343dp）。
- 双列网格：列间距 **12dp**，卡片宽 = (343 - 12) / 2 = **165.5dp**，封面高 = 宽 × 3/2 ≈ **248dp**。
- 单列列表：行高 **72dp**（封面 48×64 + 上下 4dp），行间距 8dp。
- 横滑：卡片宽 **220dp**（16:9 封面高 124dp + 文字区 56dp），间距 12dp，首尾露出 16dp 以便感知可滑。
- 基准间距序列：**4 / 8 / 12 / 16 / 20 / 24 / 32 / 40**。禁止使用非该序列的值（1dp 描边、2dp 进度线除外）。

### 3.2 竖向节奏（首页单分区）

```
分区标题行       44dp（含 8dp 上间距）
标题→卡片        12dp
卡片→卡片（行）  16dp
分区→分区        32dp
页面底部留白     24dp + 手势条区域
```

### 3.3 封面比例铁律

| 场景 | 比例 | 尺寸 |
|---|---|---|
| 竖版海报（网格/列表） | 2:3 | 165.5 × 248 dp |
| 横版剧照（大图/横滑） | 16:9 | 343 × 193 dp；横滑 220 × 124 dp |
| 剧集缩略 | 16:9 | 96 × 54 dp |
| 头像/图标 | 1:1 | 40 / 32 / 24 dp |

封面一律 `centerCrop`；加载失败用「柔光占位」（见 §5.11），不用灰块。

## 4. 视觉系统：柔光玻璃

### 4.1 设计原则

1. **光在底层**：背景不是纯色，是 3~4 个低饱和光斑的高斯融合（§4.3）。
2. **玻璃有厚度**：每层玻璃 = 模糊 + 半透明填充 + 外描边 + 内高光 + 柔影，四者缺一即"塑料片"。
3. **低饱和**：主色饱和度控制在 HSL 的 S ≤ 62%，禁止纯红/纯蓝/纯绿。
4. **层级靠明度差，不靠黑边框**：相邻层级亮度差 ≥ 4%，不用 1dp 深色分割线。
5. **高光只在上缘**：内高光仅出现在顶部 1dp 与左上圆角弧段，模拟光从上方来。

### 4.4 玻璃层级（核心表）

| 层级 | 名称 | 模糊 blur | 填充（亮 / 暗） | 描边 | 阴影 | 典型用途 |
|---|---|---|---|---|---|---|
| **L0** | 光底 | 0 | 背景渐变 | 无 | 无 | 页面背景 |
| **L1** | 卡面玻璃 | 12dp | `#FFFFFF` @ 42% / `#FFFFFF` @ 8% | 1dp `rgba(255,255,255,0.55)` / `0.14` | 0 8dp 24dp `rgba(23,32,64,0.08)` | 海报卡、列表行、剧集格容器 |
| **L2** | 浮起玻璃 | 20dp | `#FFFFFF` @ 52% / `#FFFFFF` @ 11% | 1dp `rgba(255,255,255,0.62)` / `0.16` | 0 12dp 32dp `rgba(23,32,64,0.12)` | 底部面板、筛选条、悬浮播放条 |
| **L3** | 模态玻璃 | 28dp | `#FFFFFF` @ 62% / `#FFFFFF` @ 15% | 1dp `rgba(255,255,255,0.72)` / `0.20` | 0 16dp 40dp `rgba(23,32,64,0.16)` | 播放器控制条、Toast、线路切换面板 |
| **L4** | 遮罩导航 | 32dp + scrim | `#FFFFFF` @ 54% + 黑 34% / `#0B0E16` @ 70% | 仅底边 1dp 高光 | 无 | 播放页顶部栏、详情页头图叠层 |

映射关系（记住这条曲线）：

```
模糊 12 → 20 → 28 → 32 dp    （每级 ×1.4~1.6）
填充 42 → 52 → 62 → 54%      （L3 到 L4 因为加了 scrim，填充回落）
描边 55 → 62 → 72 → 高光单边
```

> 判定规则：**模糊越大，填充越亮，直到 L4 加入 scrim 后回落**。因为大模糊会"吃掉"细节，需要更高填充来保证文字对比。

### 4.5 描边与高光做法

**外描边（必须）**——用渐变而非纯色，避免"塑料白边"：

```css
border: 1dp solid transparent;
background-clip: padding-box;
/* 用叠加层实现 135° 渐变描边 */
box-shadow: inset 0 0 0 1dp rgba(255,255,255,0.55);
```
更佳做法（两端透明度不同）：

```css
/* 伪元素描边层 */
.element::after{
  content:''; position:absolute; inset:0; border-radius:inherit; pointer-events:none;
  padding:1dp;
  background: linear-gradient(135deg,
      rgba(255,255,255,0.78) 0%,
      rgba(255,255,255,0.28) 42%,
      rgba(255,255,255,0.16) 100%);
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
}
```

**内高光（必须）**——只在上缘：

```css
box-shadow: inset 0 1dp 0 rgba(255,255,255,0.92);   /* 亮色 */
box-shadow: inset 0 1dp 0 rgba(255,255,255,0.22);   /* 暗色 */
```

**顶部高光线（用于面板/播放条，可选加强）**：宽 40%、居中、1dp、`linear-gradient(90deg, transparent, rgba(255,255,255,.9), transparent)`，仅用于 L2 及以上，且同一屏 ≤ 2 处。

**禁止**：外阴影带颜色（如蓝色光晕）、2dp 以上描边、纯白实线描边、四边等强高光。

### 4.6 圆角与间距比例

| Token | 值 | 用途 |
|---|---|---|
| `r.xs` | 4dp | 角标、状态点容器、微标签 |
| `r.sm` | 8dp | 剧集格、输入框、小按钮 |
| `r.md` | 12dp | 缩略图、横滑卡内封面 |
| `r.lg` | 16dp | 海报卡、玻璃卡（默认） |
| `r.xl` | 20dp | 悬浮播放条、大卡 |
| `r.panel` | 28dp | 底部面板顶部圆角、模态卡 |
| `r.pill` | 999dp | 胶囊按钮、搜索框、Chips |

比例约束：**圆角 ≤ 卡片短边的 1/8**（165.5dp 宽卡片用 16dp 合法；96dp 缩略图用 16dp 偏大，改用 12dp）。层级越高圆角越大（卡 16 → 浮层 20 → 面板 28），形成"软化递进"。

间距比例（1:2:3:4:5:6:8:10）即 4/8/12/16/20/24/32/40。组件内边距常用 **16dp**，组件间距常用 **12dp**，分组间距 **24/32dp**。

### 4.7 字体层级

字族：系统默认（`sans-serif` / `HarmonyOS Sans` / `MiSans` 三选一，跟随系统）。数字使用 tabular（等宽数字），避免进度/时长跳动。

| Token | 字号 | 行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|---|
| `type.display` | 28sp | 34sp | 600 | -0.6 | 详情页主标题、首启页大标题 |
| `type.h1` | 22sp | 28sp | 600 | -0.4 | 页面标题 |
| `type.h2` | 17sp | 24sp | 600 | -0.2 | 分区标题、面板标题 |
| `type.body` | 15sp | 22sp | 400 | 0 | 正文、影片副标题 |
| `type.bodyStrong` | 15sp | 22sp | 500 | 0 | 按钮文字、列表主标题 |
| `type.caption` | 13sp | 18sp | 400 | 0 | 卡片标题、说明 |
| `type.label` | 11sp | 14sp | 500 | +0.3 | 角标、元信息、Tab 小标签 |

规则：
- 一行最多 1 个 display/h1；卡片标题最多 2 行，超出省略。
- 中英混排不额外加空格；数字与单位间不断行（`2.0×`、`第 12 集` 用不换行）。
- 暗色下同字号字重可 +0 级，但**不要**靠加粗提升可读性，靠明度（见 §8）。

### 4.8 阴影体系

| Token | 值（亮） | 值（暗） | 用途 |
|---|---|---|---|
| `shadow.sm` | `0 2dp 8dp rgba(23,32,64,0.06)` | `0 2dp 8dp rgba(0,0,0,0.40)` | 小控件、Chips 浮起 |
| `shadow.md` | `0 8dp 24dp rgba(23,32,64,0.08)` | `0 8dp 24dp rgba(0,0,0,0.48)` | L1 卡片 |
| `shadow.lg` | `0 12dp 32dp rgba(23,32,64,0.12)` | `0 12dp 32dp rgba(0,0,0,0.55)` | L2 浮层 |
| `shadow.xl` | `0 16dp 40dp rgba(23,32,64,0.16)` | `0 16dp 40dp rgba(0,0,0,0.62)` | L3 模态 |

阴影永远是**冷灰蓝**（含少量蓝），不用纯黑；暗色下阴影承担"分离"职责，透明度更高。

### 4.9 封面与图像的玻璃化处理

- 封面统一加 **顶部 1dp 内高光** + 底部 40dp 渐变 scrim（`transparent → rgba(10,16,30,0.55)`），让卡片文字区自然落位。
- 禁止给封面加彩色滤镜；如需统一色调，用 `saturation 0.9 / brightness 1.02` 的上限。
- 视频画面（播放页）**不加任何玻璃色调**，仅控件层玻璃化。

## 6. 动效规范

### 6.1 时长与缓动

| Token | 时长 | 缓动 | 用途 |
|---|---|---|---|
| `m.instant` | 100ms | standard | 按压反馈、图标切换 |
| `m.fast` | 150ms | standard | Toast 进、文字变色、Chip 选中 |
| `m.base` | 200ms | standard | 控件显隐、按钮展开 |
| `m.medium` | 240ms | enter/exit | 面板滑入、悬浮条出现、玻璃浮现 |
| `m.slow` | 320ms | enter | 页面转场、共享元素放大 |
| `m.exit` | 220ms | exit | 面板关闭、页面退出 |

缓动曲线：

```
standard = cubic-bezier(0.2, 0, 0, 1)
enter    = cubic-bezier(0.05, 0.7, 0.10, 1)
exit     = cubic-bezier(0.30, 0, 0.80, 0.15)
spring   = dampingRatio 0.86, stiffness medium（仅悬浮条/长按倍速胶囊）
shimmer  = linear
```

### 6.2 节奏原则

1. **一屏一次主运动**：页面进入时只有 1 个主运动（内容上移淡入），其余元素跟随，不做各自乱飞。
2. **玻璃浮现必须同步模糊**：blur 从 0 → 目标值用 240ms 同步于透明度，禁止"先透明后模糊"。
3. **列表入场错峰 ≤ 8 项**，单项延迟 20ms，位移仅 12dp；第 9 项起无延迟。
4. **退出比进入快 20%**（220 vs 240），让界面"利落"。
5. **不使用弹性过冲**，除悬浮播放条与长按倍速胶囊（spring 轻阻尼）。
6. **手势跟手优先**：拖拽/滑动类交互必须 1:1 跟手，松手后才走曲线回位。

### 6.3 关键动效定义

| 场景 | 定义 |
|---|---|
| 页面进入（首页/详情） | 内容 `translateY 16dp → 0` + `alpha 0 → 1`，320ms enter；背景光斑同时 `scale 1.04 → 1`，360ms |
| 共享元素（海报卡 → 详情头图） | 封面矩形插值 320ms enter，圆角 16 → 20dp 同步插值；文字区 160ms 延迟淡入 |
| 底部面板 | 面板 `translateY 100% → 0` 240ms enter；scrim 0 → 32% 240ms；内容 40ms 延迟淡入 |
| 悬浮播放条 | 上移 12dp + 淡入 240ms spring；关闭时 200ms 淡出下移 |
| 播放器控制条出现 | 顶部/底部条分别 200ms enter，位移 8dp；出现后 2.8s 无操作自动隐藏（240ms exit） |
| 长按倍速 | 触觉 1 次；中央出现「2.0×」胶囊，150ms spring 弹入（scale 0.9 → 1）；松手 200ms 淡出 |
| 双击快进 | 左右各出现弧形指示 120ms 淡入，停留 600ms 后 200ms 淡出；每次 ±10s |
| 进度拖动 | 进度条 1:1 跟手；出现时间气泡（当前/总时长）随手指水平位移，180ms 淡入 |
| 收藏 | 图标 1 → 1.15 → 1 两段（120 + 120ms），同时一次轻触觉 |
| Toast | 见 §5.6 |
| 骨架循环 | 1.2s linear 无限 |
| 数字滚动（时长/集数） | 不做滚动动画，直接切换（避免干扰） |

### 6.4 全局开关

设置项「减弱动效」开启时：所有位移取消，仅保留 100ms 淡入淡出；骨架 shimmer 改为静态柔光；页面转场改为淡入。同时遵循系统 `animator_duration_scale`。

1. **头图区**（343 × 260dp）：海报模糊铺底（blur 32 + 暗化 45%）+ 底部渐变到页面底色。

6. **简介**：3 行折叠，末尾「展开」13sp 主色。
7. **相关推荐**：横滑，卡片 140 × 210（2:3）。

- 头图滚动视差：上滑 0~120dp 内，头图 `translateY = scroll * 0.4`，标题条淡出阈值 80dp。

### 7.3 播放页

- 画面全屏（16:9 居中，上下留黑），控件层：

- 错误态：画面变暗 60% + 中央玻璃卡（240×160）：错误码 + 原因 + 「换线路」「重试」。

## 7.5 导入流程（交互级）

```
粘贴 URL
  → 拉取（8s 超时，2 次重试，指数退避）
  → 识别类型：
      含 sites/lives/parses → TVBox JSON 配置
      含 "//仓库" / repos 数组 → 多仓索引
      以 var rule / export default 开头 → JS 源
      以 def / class Spider 开头 → PY 源
  → 预览面板（玻璃卡）：
      名称、类型标签、站点数、抽样 3 条站点名、告警（重复/字段缺失）
  → 勾选要启用的站点（默认全选，重复项默认不选）
  → 确认导入 → 写入本地 + 立即探测（并发 4，单站 3s）
  → Toast「已导入 12 个源，可用 10 个」
```

失败分支：格式不识别 → 面板内联提示 + 「仍以原始文本保存」；拉取失败 → 提示可否用剪贴板内容。

| 内容 | 最小对比度 | 最小字号 |
|---|---|---|
| 正文/标题（≤ 18sp） | 4.5:1 | 13sp |
| 大字号（≥ 18sp 或 ≥ 14sp 加粗） | 3.0:1 | 18sp |
| 图上的标题文字 | 4.5:1（含 scrim 后实测） | 15sp |
| 元信息/角标 | 4.5:1（若 3.5~4.5 之间必须 ≥ 12sp 且非关键信息） | 11sp |
| 占位符文字 | 3.0:1 | 13sp |
| 状态点/图标（表意） | 3.0:1 | 6dp |

### 8.2 图上文字规则（强制）

1. 任何压在图片上的文字，必须叠 **底部渐变 scrim**：`rgba(10,16,30,0) → rgba(10,16,30,0.78)`，高度 ≥ 文字区 1.6 倍。
2. 全宽大图上使用「玻璃信息条」而非裸字：条内文字对条内底色测对比。
3. 亮色海报（高亮度封面）同样加 scrim，因为白字对亮图不可控。
4. 角标（"更新至 12 集"）必须自带玻璃底，禁止直接压图。

### 8.3 玻璃与文字的兼容规则

| 玻璃背景 | 允许文字色 | 禁止 |
|---|---|---|
| L1 亮（白 42%） | primary / secondary / tertiary | 纯白文字 |
| L1 暗（白 8%） | primary / secondary（tertiary 仅 12sp+） | `text.disabled` 承载信息 |
| L3 亮（白 62%） | primary / secondary | 浅灰次级色（< #79839A） |
| 画面上的 L4 | 一律白色 + scrim 兜底 | 深色文字 |

### 8.4 可访问性

- 全部触控 ≥ 44dp；图标按钮视觉 20~24dp，触区 44dp。
- 支持系统字体缩放 1.0 / 1.15 / 1.3：卡片标题 1.3 倍时降至 1 行 + 更高卡片；不允许文字溢出裁切。
- 所有状态不能只靠颜色区分（在线/超时需配图标或文案，如"超时 8s"）。
- TalkBack：封面朗读「影片名，年份，类型，更新至 N 集」；进度条播报「已播放 32%，剩余 18 分钟」。

## 9. 性能与降级（玻璃是性能敏感项）

| 条件 | 策略 |
|---|---|
| 常规设备 | L1~L3 实时模糊（RenderEffect / RenderScript 替代 / Compose graphicsLayer + blur） |
| 列表快速滚动 | 卡片模糊降级为「预渲染模糊位图」（缓存 1 张按卡片尺寸缩放），滚动停止 300ms 后恢复实时 |
| 同屏限制 | 大面积实时模糊 ≤ 3 块；超出的自动降为纯半透明填充 |
| 低端机（RAM < 4GB 或 API < 29 或用户设置「省电」） | 全局关闭实时模糊，玻璃改为填充 86%/12% + 描边 + 高光（保留"玻璃感"，去掉模糊） |
| 播放中 | 控件层允许模糊；画面区域永不模糊 |
| 刷新率 | 所有动效在 60Hz 与 120Hz 下时长一致（按时间而非帧数） |

降级后的玻璃仍必须保留：外描边渐变 + 上缘内高光 + 柔影，否则会退化为"半透明色块"。

## 10. 实现映射（Android）

| 设计项 | 实现建议 |
|---|---|
| 背景柔光 | Compose：`Brush.radialGradient` × 3 + `drawBehind`；View：`GradientDrawable` 多层叠加 |
| 玻璃层 | API 31+ `RenderEffect.createBlurEffect` + `View.setRenderEffect`；Compose `Modifier.graphicsLayer{renderEffect}`；低版本用 BlurView/预渲染位图 |
| 渐变描边 | `Modifier.border` 不支持渐变 → 用 `drawWithContent` + `Path` 双色描边，或 1dp 内描边 + 叠加渐变层 |
| 内高光 | `drawLine` 顶部 1dp 或 `Brush.verticalGradient` 单像素层 |
| 间距/圆角 | 统一从 `Dimens.kt` 读取，禁止散落硬编码 |
| 字体 | `Typo.kt` 定义 §4.7 全部 token |
| 动效 | `Motion.kt` 定义 §6 时长与 `CubicBezierEasing`；统一 `AnimationSpec` |
| 骨架 shimmer | `infiniteRepeatable` + `Brush.linearGradient` 位移 |
| 列表 | `LazyVerticalGrid`（双列，`GridCells.Fixed(2)`，间距 12/16dp） |
| 播放 | Media3 `PlayerView` + 自定义 `ControllerOverlay`（禁用默认控制条） |
