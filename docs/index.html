可读性底线

图上文字必须叠底部 scrim（0 → 0.78）；正文 ≥ 4.5:1，次要 ≥ 3.5:1 且 ≥ 12sp。亮色海报与暗色海报一视同仁。

性能降级

同屏实时模糊 ≤ 3 块；列表滚动降级为预渲染模糊位图；低端机关闭 blur，仅保留填充 + 描边 + 上缘高光。

层级递进

圆角随层级上升：卡 16 → 浮层 20 → 面板 28。模糊与填充同向递增，L4 因加 scrim 填充回落。
